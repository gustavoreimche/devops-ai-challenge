# devops-ai-challenge

Um snapshot de configuração de pipeline e deploy de uma plataforma fictícia
com múltiplos serviços.

- `padrao/` é o padrão que todo serviço deveria seguir, descrito em
  [`padrao/POLICY.md`](padrao/POLICY.md).
- `frota/` contém três serviços reais, cada um num estado diferente de
  aderência a esse padrão.

Os arquivos `.ci/pipeline.yml` são cópias extraídas para revisão.

## O cenário

Você acabou de assumir a plataforma. A frota precisa estar apta a ir para
produção, e você tem dois consultores especialistas para executar o que for
preciso. Queremos entender o que você faria.

## Como vai ser

- Use o seu setup de IA do jeito que usa no dia a dia: agents, skills, o que
  for seu. Não existe ferramenta certa.
- Compartilhe a tela e pense em voz alta. O caminho importa tanto quanto o
  resultado.
- Pode perguntar ao entrevistador a qualquer momento.
- Você tem até 40 minutos. Não se espera que termine tudo; escolher o que
  fica de fora também conta.

## Ao final, mostre

1. O que você encontrou, em ordem de prioridade, e por quê.
2. Como dividiria o trabalho entre os dois consultores.
3. Uma mudança concreta feita por você, a que achar que mais vale.
